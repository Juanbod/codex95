# Codex95: краткий запуск

[English README](README.md)

Текущая тестовая версия: **v0.4.0**. Проект всё ещё находится в активной
разработке и создаётся при существенной помощи ИИ и вайбкодинга.

Codex95 позволяет давать обычные текстовые задания старому компьютеру с
Windows 95: создавать и редактировать файлы, собирать программы и запускать их.

Система состоит из двух частей:

| Компьютер | Что на нём запускается |
| --- | --- |
| Toshiba Libretto или другой ПК с Windows 95 | Лёгкий клиент `CODEX95W.EXE` |
| Современный Windows/macOS/Linux-компьютер | Bridge, который обращается к OpenAI API |

API-ключ не передаётся на Windows 95. Оба компьютера должны находиться в одной
доверенной локальной сети.

## Самый простой запуск

1. Установите [Node.js](https://nodejs.org) на современный компьютер.
2. Запустите bridge из корня проекта:

   - Windows: `START_CODEX95_WINDOWS.cmd`
   - macOS: `START_CODEX95_MAC.command`

3. В открывшейся странице введите OpenAI API-ключ.
4. Перенесите на Windows 95 два файла:

   - `build\CODEX95W.EXE`
   - `client\CODEX95.INI.example`, переименовав его в `CODEX95.INI`

5. Положите оба файла в одну папку и запустите `CODEX95W.EXE`.
6. Создайте проект, напишите задачу и нажмите **Build it**.

Обычно клиент сам находит bridge через `Host=auto`. Если не находит, откройте
**Options > Settings** и укажите локальный IP современного компьютера, например
`192.168.1.50:8787`.

В поле **Model** можно выбрать модель из списка или вручную вписать другой
model ID, если он доступен вашему OpenAI API-аккаунту.

## Какую модель выбрать

| Модель | Когда использовать |
| --- | --- |
| `gpt-5.6-luna` | Самый дешёвый вариант по умолчанию для небольших программ и правок |
| `gpt-5.6-terra` | Разумный баланс качества кода и стоимости API |
| `gpt-5.6` / `gpt-5.6-sol` | Сложная профессиональная работа; оба ID ведут на Sol |
| `gpt-6-astra` | Самые сложные многоэтапные задачи; самая высокая цена токенов |
| `chat-latest` | Обновляемая Instant-модель из ChatGPT вместо фиксированной версии |

Старые варианты GPT-5.5 и GPT-5.4 тоже оставлены. При смене модели у проекта
будет отдельная история контекста. Уже выбранная модель из `CODEX95.INI` не
меняется после обновления; `gpt-5.6-luna` используется только в новой установке.
Доступность зависит от API-аккаунта и этапа развёртывания модели. Если выбранная
модель пока недоступна, ошибка API появится в чате без изменения файлов проекта.

Актуальная доступность и цены приведены в официальном
[списке моделей OpenAI](https://developers.openai.com/api/docs/models).

## Бесплатная проверка без API

Чтобы проверить сеть и клиент без расходов:

- Windows: `START_MOCK_WINDOWS.cmd`
- macOS: `START_MOCK_MAC.command`

Mock-режим не обращается к OpenAI, но проверяет полный обмен командами между
bridge и Windows 95.

## Обновление клиента по Ethernet

Bridge отдаёт текущий файл `build\CODEX95W.EXE` старому компьютеру по локальной
сети. Это удобно, когда Libretto уже подключён по Ethernet.

1. Обновите репозиторий и файл `build\CODEX95W.EXE` на современном компьютере.
2. Запустите bridge и оставьте окно открытым.
3. На Windows 95 откройте `CODEX95W.EXE`.
4. Согласитесь со всплывшим предложением или выберите
   **Options > Update Codex95...**.
5. Подтвердите версию. Клиент проверит размер и заголовок EXE, скачает новый
   файл и перезапустится.

Настройки `CODEX95.INI`, чаты и проекты при этом сохраняются. Предыдущий EXE
остаётся рядом как `CODEX95W.OLD`, а при ошибке копирования восстанавливается
автоматически. Проверку обновлений при запуске можно отключить в Settings.

## Русский и японский текст

Codex95 v0.4.0 передаёт сообщения через bridge в UTF-8, а на самом старом
компьютере переводит их в системную ANSI-кодировку без зависимости от UTF-8
codepage, которой в Windows 95 обычно нет. На японской Windows 95 это обычно
CP932/Shift-JIS, на русской - CP1251. Интерфейс также использует системный шрифт
установленной локализации.

Ограничение старой Windows: один ANSI-интерфейс обычно не отображает русский и
японский идеально одновременно. Японский текст нормально отображается на
японской системе с подходящими шрифтами, русский - на русской системе или при
наличии нужной кодовой страницы и шрифтов.

## Важно

- Проект экспериментальный и может изменять или удалять файлы.
- Сначала используйте доступ только к выбранному проекту.
- Не открывайте порты bridge в интернет.
- Храните резервную копию диска Windows 95.
- macOS поддерживается как современный bridge-компьютер. Сам Win95-клиент
  запускается только на Windows 95-совместимой системе.
- Сам bridge пока не обновляется с Windows 95: сначала обновляется репозиторий
  на современном компьютере, затем клиент устанавливает новый EXE по Ethernet.

Полная документация, сборка и устранение проблем описаны в
[README.md](README.md).
